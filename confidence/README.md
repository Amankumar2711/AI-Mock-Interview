# 🎙️ AI Interview Analyzer

A privacy-first, multimodal behavioral analysis pipeline that runs completely locally on your machine. This project analyzes spoken interview answers using advanced Acoustic and Natural Language Processing to generate a deterministic confidence score based on human vocal traits.

##  System Architecture

Instead of relying on opaque Machine Learning predictors, this engine utilizes a transparent, deterministic **40/40/20 Rubric**. 
The system evaluates your answers using a strict **Penalty-Based** deduction system against a starting score of 100.0.

### 1. Fluency & Pacing (40%)
* **Words Per Minute (WPM):** Checks for the "Goldilocks Zone" of `90 - 150 WPM`. 
  * Under 90 WPM: Deducts `0.5` points per word below threshold (Max -13.33).
  * Over 150 WPM: Deducts `0.5` points per word above threshold (Max -13.33).
* **Filler Word Ratio:** Calculates `Filler Words / Total Words`. Directly scales the penalty based on your ratio, up to a maximum penalty of `-13.33` (e.g. `filler_ratio * 13.33`).
* **Unvoiced Pauses:** Detects pauses exceeding `0.40s`. Applies aggressive penalties (`(Pause - 0.4) * 30`) up to `-13.33`.

### 2. Vocal Stability (40%)
Uses `OpenSMILE` to physically measure micro-tremors in your vocal cords to detect physiological nervousness.
* **Jitter (Voice Tremor):** Heavily penalizes frequency instability over `0.02` (Max -20.0).
* **Shimmer (Volume Wavering):** Penalizes amplitude instability over `0.80 dB` (Max -20.0).

### 3. Linguistic Certainty (20%)
* **Hedge Word Ratio:** Calculates `Hedge Words / Total Words`. Directly scales the penalty up to `-20.0` points (e.g. `hedge_ratio * 20`). 

###  The "Uncooperative" Failure State
If you attempt to trick the engine by remaining entirely silent, or if the *only* words you speak are filler words (`Total Words - Fillers == 0`), the engine mathematically recognizes the evasion. It bypasses all normal logic and automatically locks your final score to a failing **26.67**.

### ⚙️ The ML Stack
* **Whisper (C++ Binary):** We use `whisper.cpp` (ggml-small.en) for lightning-fast, offline Speech-to-Text transcription.
* **OpenSMILE:** A world-class academic C++ library that physically measures 88 low-level acoustic descriptors.
* **spaCy:** NLP engine (`en_core_web_sm`) used for tokenization and regex math.

##  Repository Structure & File Use-Cases

The entire pipeline is driven by the `app/` folder. Here is exactly what every file and folder does:

### The Root Directory
* **`setup.py`**: A deployment script that connects to GitHub/HuggingFace to automatically download the Whisper C++ binaries and `small.en` weights so you don't have to compile them.
* **`requirements.txt`**: Contains the Python dependencies (`fastapi`, `uvicorn`, `pydub`).
* **`bin/`**: A hidden folder generated by `setup.py` that holds the `main.exe` binary and AI models.
* **`processed_audio/`**, **`recordings/`**, **`transcripts/`**: Auto-generated runtime folders that temporarily hold your interview audio and text files while the pipeline processes them.

### The Application Core (`app/`)
* **`app/interview_runner.py`**: The main entry point. Orchestrates the terminal UI loop and prints the highly-detailed score dashboard.

### The Pipeline Services (`app/services/`)
This folder contains the actual logic modules, executing in a very specific order:
1. **`question_generator.py`**: Holds the bank of interview questions to ask.
2. **`question_speaker.py`**: Uses Python TTS (Text-to-Speech) to speak the question out loud to the user.
3. **`recorder.py`**: Interacts with the user's microphone to record their answer as a raw `.wav` file.
4. **`audio_preprocessing.py`**: Cleans up the raw `.wav` file, forcing it into a strict 16kHz, 16-bit Mono PCM format required by the ML engines.
5. **`interview_pipeline.py`**: The "Traffic Controller". It routes the cleaned audio to Whisper and OpenSMILE simultaneously, and calculates the total audio duration.
6. **`whisper_transcriber.py`**: Triggers the `bin/main.exe` subprocess to transcribe the audio into raw English text.
7. **`text_feature_extractor.py`**: The NLP engine. Feeds the transcript through `spaCy` and Regex to precisely count Filler Words, Hedge Words, and total Word Count.
8. **`egemaps_extractor.py`**: The Acoustic engine. Uses OpenSMILE to extract the physical parameters of the user's voice into a JSON file.
9. **`audio_confidence_analyzer.py`**: Sifts through the massive OpenSMILE JSON to isolate penalty values specifically for Jitter, Shimmer, and Unvoiced Pauses.
10. **`confidence_engine.py`**: The Master Scoring Engine. Starts at 100 points, applies all mathematical penalties, calculates WPM, and outputs the final Confidence Score.
11. **`recommendation_engine.py`**: Looks at the final score and assigns a label (Proceed / Borderline / Reject).

##  Installation & Setup

### 1. Create a Virtual Environment
```bash
python -m venv .venv
.venv\Scripts\activate
```

### 2. Install Python Dependencies
```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

### 3. Run the Setup Script
```bash
python setup.py
```

---

##  Usage

To start the mock interview, ensure your microphone is plugged in and run:

```bash
python -m app.interview_runner
```
